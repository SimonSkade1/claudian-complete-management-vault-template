# optional-extensions

Opt-in add-ons that are not part of the core template. Each subfolder contains a `SETUP.md` (what it is + install steps written for Claude to execute) and an `assets/` folder with the ready-made files; install one by telling Claude in this vault: "set up the <name> extension".

1. `spare-usage-burner/` — adds a `projects-claude/` side-projects tree worked autonomously by scheduled headless vna-controller sessions that spend Claude-plan usage which would otherwise expire before the weekly reset.
