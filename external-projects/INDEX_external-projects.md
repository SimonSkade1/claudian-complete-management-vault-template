# external-projects

Code projects and other repos that live alongside the vault but keep their own git history — each subfolder is its own git repo, deliberately not tracked by the vault repo.

The `.gitignore` managed block (regenerated by `non-markdown/update-external-ignores.sh`, also run nightly by the review wrapper) auto-ignores every subfolder here that contains a `.git`, so the vault repo never records gitlinks for them. List your projects in this INDEX, one line each.
